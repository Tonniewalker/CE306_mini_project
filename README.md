# PRE-FOOD

เว็บแอปสั่งอาหารล่วงหน้า เลือกร้าน สั่งอาหาร เลือกเวลารับ แล้วมารับตามคิว

## ฟีเจอร์หลัก

ระบบมีผู้ใช้ 3 แบบ

- **ผู้ใช้ (ลูกค้า)** สมัครสมาชิก เลือกร้าน สั่งอาหาร เลือกเวลารับภายในวันนั้น ชำระเงินแบบจำลอง ติดตามสถานะและเลขคิว ยกเลิกออเดอร์ ดูประวัติและสั่งซ้ำ
- **ร้านค้า** รับ/ปฏิเสธออเดอร์ อัปเดตสถานะ ยืนยันการรับอาหารด้วยเลขคิว จัดการเมนูพร้อมรูป ตั้งค่าร้าน (เวลาเปิด-ปิด เปิด/ปิดรับออเดอร์) และดูรายงานยอดขาย
- **Admin** ตรวจและอนุมัติใบสมัครร้านค้า ดูภาพรวมระบบ ระงับ/เปิดร้านและบัญชีผู้ใช้ ดูออเดอร์ทุกร้าน

## เทคโนโลยีที่ใช้

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: SQLite
- ล็อกอิน: JWT และเข้ารหัสรหัสผ่านด้วย bcrypt

## วิธีติดตั้ง

1. ดาวน์โหลดโปรเจกต์

   ```bash
   git clone https://github.com/Tonniewalker/CE306_mini_project.git
   cd CE306_mini_project
   ```

2. ติดตั้งแพ็กเกจของ backend

   ```bash
   cd backend
   npm install
   ```

3. สร้างไฟล์ `.env` จากไฟล์ตัวอย่าง

   ```bash
   # Windows (PowerShell / Command Prompt)
   copy .env.example .env

   # macOS / Linux
   cp .env.example .env
   ```

   เปิดไฟล์ `.env` แล้วเปลี่ยน `JWT_SECRET` เป็นข้อความสุ่มยาวๆ อะไรก็ได้

   | `PORT` | พอร์ตของเว็บ (ค่าเริ่มต้น 3000) |
   | `JWT_SECRET` | คีย์ลับสำหรับสร้าง token ล็อกอิน |
   | `JWT_EXPIRES_IN` | อายุการล็อกอิน เช่น `7d` |
   | `DEV_ALWAYS_OPEN` | `true` = ทุกร้านเปิด 24 ชั่วโมง ใช้ตอนทดสอบนอกเวลาร้าน, `false` = ใช้เวลาเปิด-ปิดจริง |

4. เปิดเซิร์ฟเวอร์

   ```bash
   npm start
   ```

   ครั้งแรกระบบจะสร้างฐานข้อมูลให้เอง พร้อมร้านตัวอย่าง เมนู 12 รายการ และบัญชีทดสอบ

5. เปิดเบราว์เซอร์ไปที่ **http://localhost:3000**

## วิธีใช้งาน

### บัญชีทดสอบ

| บทบาท | อีเมล | รหัสผ่าน |
|---|---|---|
| ร้านค้า | `store@prefood.dpu.ac.th` | `store1234` |
| Admin | `admin@prefood.dpu.ac.th` | `admin1234` |

บัญชีลูกค้าให้กด **เข้าสู่ระบบ → สมัครสมาชิก** ที่หน้าแรก

### ลองสั่งอาหาร (ผู้ใช้ → ร้านค้า)

1. ล็อกอินเป็นลูกค้า เลือกร้าน กดเพิ่มเมนูลงตะกร้า
2. ไปที่ตะกร้า เลือกเวลารับ แล้วกด **ชำระเงิน** (QR จำลอง กด "ชำระเงินแล้ว" ได้เลย) จะได้เลขคิว
3. ล็อกอินเป็นร้านค้า (แนะนำเปิดอีกเบราว์เซอร์หรือหน้าต่างไม่ระบุตัวตน) ที่บอร์ดออเดอร์กด **รับออเดอร์** → **อาหารพร้อมแล้ว**
4. ตอนลูกค้ามารับ กรอกเลขคิวในช่อง **ลูกค้ามารับอาหาร** แล้วกดยืนยัน (หรือลูกค้ากด **ได้รับอาหารแล้ว** เองก็ได้)

### เปิดร้านใหม่ (ร้านค้า → Admin)

1. ที่ท้ายหน้าแรกกด **สมัครเป็นร้านค้า** กรอกใบสมัคร (อีเมลต้องไม่ซ้ำกับบัญชีที่มีอยู่)
2. ล็อกอินเป็น Admin ที่หน้าภาพรวมกด **อนุมัติ** ในการ์ดใบสมัครร้านค้า ระบบจะสร้างบัญชีร้านและแสดงรหัสผ่านชั่วคราว
3. ร้านใหม่ล็อกอินด้วยอีเมลและรหัสนั้น แล้วเปลี่ยนรหัสผ่านได้ที่ **ตั้งค่าร้าน**

### เวลาเปิด-ปิดร้าน

ลูกค้าสั่งได้เฉพาะตอนร้านเปิด (ร้านตัวอย่างเปิด 09:00–19:00) ถ้าจะทดสอบนอกเวลานี้ ให้ตั้ง `DEV_ALWAYS_OPEN=true` ในไฟล์ `.env` แล้วเปิดเซิร์ฟเวอร์ใหม่

## คำสั่ง

รันในโฟลเดอร์ `backend`

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `npm start` | เปิดเซิร์ฟเวอร์ |
| `npm run db:reset` | ลบฐานข้อมูลแล้วสร้างใหม่พร้อมข้อมูลตัวอย่าง |

## โครงสร้างโปรเจกต์

```
backend/
  src/
    server.js        จุดเริ่มเซิร์ฟเวอร์
    db/              โครงสร้างฐานข้อมูล (schema.sql) และข้อมูลตัวอย่าง (init.js)
    routes/          API แยกตามส่วน (auth, orders, admin ฯลฯ)
    middleware/      ตรวจการล็อกอินและสิทธิ์
  uploads/           รูปที่ร้านอัปโหลด (สร้างอัตโนมัติ)
frontend/
  *.html             หน้าเว็บ (stores = หน้าแรก, store-* = ร้านค้า, admin-* = Admin)
  css/               สไตล์ (style.css รวมไฟล์ย่อยทั้งหมด)
  js/                โค้ดที่ใช้ร่วมกันทุกหน้า (api.js, ui.js, nav.js)
```
